# ارزینه — Arzineh

ارزینه یک اپلیکیشن اندرویدی RTL برای رصد قیمت ارزها و تبدیل سریع آن‌ها به تومان است. طراحی محصول از ابتدا برای صفحه موبایل، استفاده یک‌دستی، خوانایی فارسی و حرکت‌های نرم ساخته شده است.

## چیزهایی که ساخته شده

- `android/` — پروژه آماده Android Studio با Kotlin + Jetpack Compose
  - صفحه خانه با هدر زنده، کارت قهرمان، خلاصه بازار و ارزهای محبوب
  - صفحه نرخ‌ها با دسته‌بندی «همه / ارزها / دیجیتال»، جستجو و فهرست نرخ‌ها
  - تبدیلگر مقدار با انتخاب ارز مبدا، تبدیل به تومان و مقادیر سریع
  - ناوبری پایین صفحه و ترنزیشن بین صفحات
  - تم تیره، رنگ‌بندی اختصاصی، لوگوی برداری و آیکن لانچر
- `web/` — پیش‌نمایش تعاملی و responsive برای دیدن طراحی در مرورگر بدون نصب Android Studio
  - داده نمایشی فارسی برای دلار، یورو، پوند، درهم، لیر، بیت‌کوین، اتریوم، تتر و سولانا
  - تعامل کامل تب‌ها، جستجو، تبدیلگر، جابجایی ارز و انیمیشن‌ها
  - `web/assets/logo-mark.svg` نشان اختصاصی ارزینه

## اجرای پیش‌نمایش طراحی

از ریشه پروژه:

```bash
python3 -m http.server 4173 --directory web --bind 0.0.0.0
```

سپس آدرس `http://localhost:4173` را باز کنید.

## اجرای نسخه اندروید

پوشه `android/` را در Android Studio باز کنید و روی emulator یا گوشی اجرا بگیرید. این نسخه با `minSdk 26`، `compileSdk 35` و Compose ساخته شده است.

نرخ‌های فعلی در این نسخه برای نمایش UX به عنوان fallback داخل برنامه قرار گرفته‌اند. برای انتشار عمومی، فایل `MainActivity.kt` را به سرویس نرخ مورد اعتماد خود (با cache محلی، زمان آخرین به‌روزرسانی و مدیریت خطا) متصل کنید؛ توکن یا کلید سرویس نباید داخل کلاینت قرار بگیرد.

## نکته تحویل

این محیط دسترسی به تلگرام کاربر، ارسال فایل خارجی یا ضبط واقعی صفحه ندارد؛ هیچ توکن یا اطلاعات خصوصی تلگرام داخل پروژه ذخیره نشده است. فایل‌های پروژه در همین checkout آماده‌اند و می‌توان آن‌ها را از اینجا دریافت و در تلگرام ارسال کرد.
